# Sistema de Gestão de Projetos

Aplicação desktop acadêmica para organizar usuários, equipes, projetos e tarefas, com interface Java Swing e arquitetura MVC.

## Funcionalidades

- Cadastro de usuários e equipes.
- Gestão de projetos e tarefas.
- Relatórios de acompanhamento.

## Tecnologias

Java, Swing, programação orientada a objetos e MVC.

## Estrutura

O código-fonte está em `SistemaGestaoProjetos/SistemaGestaoProjetos/src/`, separado em `controller`, `model` e `view`. O ponto de entrada é `Main.java`.

## Executar

1. Instale um JDK compatível com o projeto e abra `SistemaGestaoProjetos` no IntelliJ IDEA.
2. Configure o SDK e a pasta `SistemaGestaoProjetos/src` interna como raiz de código-fonte, se necessário.
3. Compile e execute `Main.java`.

Os arquivos `.class` são gerados durante a compilação e não fazem parte da versão corrente do código-fonte. O histórico anterior permanece preservado.
